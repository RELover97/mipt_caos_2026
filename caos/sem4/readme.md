# Ассемблер x86-64

Для возможности ввода данных с клавиатуры и вывода на экран используем библиотеку `simple_io_x64.s`. Для этого компилируем нашу программу `prog.s` так:
```
gcc prog.s simple_io_x64.s -o app
```

## Задача проверки числа на чётность

Вводится целое число с клавиатуры. 

Вывести на экран число 1, если исходное число нечётное, и 0, если чётное.

## Задача на поиск максимального элемента массива

Задан массив целых чисел в памяти. Вывести на экран его максимальный элемент.

## Задача вычисления суммы чисел

С клавиатуры вводится натуральное число. Вывести на экран сумму первых натуральных чисел до указанного числа включительно.
