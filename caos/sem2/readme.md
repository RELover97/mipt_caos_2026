## Представление вещественных чисел

Покажем, как написать двоичное представлние числа `-10.125` в типе `float`:

1. В типе `float` на знак отводится 1 бит, на порядок - 8 бит, на мантиссу - 23 бита

2. Переведём абсолютное значение числа в двоичную систему счисления:

$10 = 1010_2$

$0.125 = 0.001_2$

$10.125 = 1010.0.001_2$

3. Нормализуем число:

$1010.0.001_2 = 1.010001_2 × 2^3$

Мантисса будет $1.010001_2$, порядок $E = 3$

4. Знак

Число отрицательное, поэтому знаковый бит равен $1$

5. Экспонента

Экспонента хранится со смещением $bias$; для `float` оно равно `127`.

$bias + E = 130$

$130 = 10000010_2$

$E = 10000010_2$

6. Мантисса

Вместо $1.010001_2$ храним $010001_2$ и дополняем ведущими нулями до 23 бит

7. Итого

$1|10000010|01000100000000000000000$


ULP

- unit in the last place

- расстояние между двумя соседними числами соседними числами с плавающей точкой не фиксировано

- ULP - вес самого младшего бита мантисса при фиксированной экспоненте

- иными словами, ULP - "цена деления" вычислительной линейки, которая растягивается по мере того, как увеличивается само число

- в IEEE-754 расстояние между соседними числами удваивается каждый раз, когда мы переходим через степень двойки

Пример

Число | Экспонента ($2^E$) | Расчёт ULP ($2^E - 23$) | Значение ULP (десятичное) 

$1.0$ | $2^0$ | $2^{-23}$ | $\approx 0.000000119$

$2.0$ | $2^1$ | $2^{-22}$ | $\approx 0.000000238$

$8.0$ | $2^3$ | $2^{-20}$ | $\approx 0.000000953$

$16 777 216.0$ | $2^24$ | $2^1$ | $2.0$

Как понять ULP = $2.0$? Если мы храним во `float` число $16 777 216.0$, то следующим представим во `float` числом будет $16 777 218.0$, при этом $16 777 216.0 + 1 = 16 777 216.0$!
